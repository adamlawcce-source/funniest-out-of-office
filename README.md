A tiny Node 22 program for the make.fun bounty
[The Funniest Out-of-Office](https://make.fun/bounty/u-kreutzx-the-funniest-out-of-office-054815cf).

`main.ts` writes one out-of-office auto-reply to `/output/entry.txt`: the
sender is away until Monday, and their toddler has taken over the inbox,
replying to everyone with the same word — "no". The twist lands on the
very last word, in a voice a real parent could actually set. No network,
no randomness, no input — the same line on every run.

Run it with Node 22:

```sh
node main.ts
```
